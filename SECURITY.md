# Security

## Report a problem privately

Do not open a public issue for a security problem.

- Preferred: use **Report a vulnerability** on this repository's Security tab (GitHub private vulnerability reporting).
- Or email info@modernai.io with "Security: Gravity test kit" in the subject.

Please include what is affected, how to reproduce it, and what an attacker could do with it.

We will reply to confirm we received your report, and we will tell you when it is fixed.

## Supported versions

Only the latest version on the default branch is supported.

## Scope

This repository only. For a problem in a Modern AI product or website, use the same email.
